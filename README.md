## Project overview

Cryptocurrency transactions can form large networks of interacting addresses. Looking at transactions as a graph can reveal relationships and patterns that may be difficult to identify by examining individual transactions alone. This project explores graph-based machine learning for cryptocurrency fraud detection and pairs the detection task with explainability, so that model assessments can be interpreted and investigated in a forensic context.

The repository includes the project research paper and a Google Colab notebook. The paper describes the research and its context; the notebook contains the project workflow and implementation. Please consult those files for the exact data, preprocessing steps, model configurations, experiments, and findings.

## Project goals

- Represent cryptocurrency activity in a way that captures relationships between entities or transactions.
- Apply machine-learning methods to identify activity associated with fraud.
- Provide explanations that help users understand the factors or graph context behind model predictions.
- Support forensic analysis by connecting detection with interpretable evidence and research documentation.
